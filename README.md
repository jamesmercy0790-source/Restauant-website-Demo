# Aurelle — Neighborhood Bistro

A responsive four-page, white-and-blue restaurant website demo built with plain HTML, CSS, and JavaScript, with gentle scroll and hover animations (respecting reduced-motion settings). No build step or package installation is required; open `index.html` locally or deploy the repository as a static site on Vercel.

## Pages

- `index.html` — home and restaurant story
- `menu.html` — seasonal menu with working category filters
- `gallery.html` — responsive photo gallery with a lightbox
- `contact.html` — location, hours, directions, and reservation request form

## Demo content

The restaurant name, menu, address, hours, phone number, and images are sample content because client assets and business details were not included. The reservation form validates the date (closed Mondays) and seating times against the opening hours, then displays a local confirmation only; connect a booking provider or backend before accepting real bookings. Replace the sample Instagram destination and contact details before launch.

## Deploy

Import this GitHub repository into Vercel. The site is static and needs no framework preset, build command, or output directory.
